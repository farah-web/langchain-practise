# LangChain Practise 

This repository contains hands-on practice examples using **LangChain** with multiple LLM providers such as **OpenAI, Google Gemini, Anthropic, and Hugging Face**.

It is intended for learning and experimenting with:
- Chat models
- Prompt engineering
- Retrieval-Augmented Generation (RAG)
- Structured outputs using Pydantic
- Multi-LLM integrations

---

## Environment Variables

Create a `.env` file in the project root (this file is ignored by Git):

```env
OPENAI_API_KEY=your_openai_api_key
HUGGINGFACEHUB_API_TOKEN=your_huggingface_token
```
## Tech Stack
- Python
- LangChain
- Pydantic
- OpenAI
- Hugging Face
